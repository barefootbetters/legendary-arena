## Context (Read First)

- **Rules v23** (`docs/legendary-universal-rules-v23.md`): Henchmen and Villains caused to enter the City at an unusual time still do their Ambush as they enter (~L2329, L2423, L2831, L3224-3227). "If an effect causes 'each player' to gain a Wound (or do anything else), start with the current player then go clockwise" (~L2247, D-24780). Captured Heroes on an escaping Villain default to the Escape Pile — "They used to be KO'd" (D-24657); Bullseye's printed "KO that Hero" is a card-specific override of that default.
- **Why one WP, not two.** All seven lines belong to one 4-card group led by one Mastermind (Taskmaster), every effect reuses a shipped seam (the capture/attach structure, the dynamic "N+" fight-cost, the D-24817 fight-pick queue, the D-24351 villain-deck reveal bridge, the Viper inline-Escape skeleton), and one D-entry locks them — so one packet keeps the group's test file, marker edit and feed regen in one place. This mirrors WP-902 (the sibling group, 6 primitives, one D-entry, one test file). The two mechanic families here (henchman / villain-deck / City movement vs. the Bullseye capture lifecycle) share no **new** seam, but each reuses only shipped plumbing, so the net-new surface stays at five small handlers — within the WP-838 (five primitives) / WP-872 (three) band and below the ~10-code-file split threshold. **If pre-flight judges the surface too large, the clean cleave is A (Jester / Joystick / Jack O'Lantern) vs. B (Bullseye); each half is ~3 lines and WP-902-sized.** No client file changes: the generic seat-choice prompt renders the one new pick.
- **Bullseye Fight = the shipped `gain-attached-hero` (D-24270).** "The player of your choice gains the captured Hero" is the HYDRA Kidnappers pattern verbatim (`capture-pile-hero` Ambush + `gain-attached-hero` Fight). Per the D-24335 dominated-option collapse, a printed "choose a player to gain it" resolves deterministically to the current (fighting) player; the generic `awardAttachedHeroes` at the fight site already does this, so Bullseye's Fight needs only the marker — no new handler, no fight-pick, no new kind.
- **Bullseye's "4+" grows for free.** Because the attack is dynamic (base 4 + the costs of captured Heroes, read from `G.villainAttachedHeroes`), capturing a Hero into that structure is exactly "+Attack equal to that Hero's cost," and awarding or KO-ing it reverts the Attack to 4 — the move, the bot and the City `fightCost` projection agree by construction (`resolveFightCost` is the single authority). Bullseye is **never** registered in `G.villainVariableAttack` / `G.villainAttackPerCaptured` (that would short-circuit the sum, L473-478).
- **Bullseye's blind icon choice collapses (D-24335 philosophy).** "Choose … then reveal" is a blind choice (no look-ahead). Bullseye's Ambush strengthens the Villain, so the self-interested villain choice maximizes the capture chance; Attack is the more common Hero icon, so D-24860 collapses the blind choice to `[icon:attack]`. Deterministic, keyword-less, self-narrating; no seat choice. (If the top Hero lacks an Attack icon, nothing is captured.)
- **Jester's reorder collapses to revealed order (dominated-option).** "Put the rest back in any order" is a reorder with no deterministic look-ahead benefit, so the non-Henchman remainder returns to the deck top in revealed order (option-0 of the Nightbringer reorder, generalized) — no interactive 4-card reorder is built. Henchmen enter the City in revealed order, each doing its own Ambush via `resolveVillainCityEntry`.
- **The Henchman-to-City pick rides D-24817.** Joystick's Ambush and Jack O'Lantern's Fight queue the same `PendingVillainFightPick` (the executor runs for both timings), and the shipped `onMove` opener parks a one-step seat choice listing every Henchman across all Victory Piles. A Henchman re-entering the City is a drawback (another Villain to fight), and the line is mandatory, so the options are ordered by ascending City Attack (index 0 = least threatening = the default the timeout / bot-ally / sim keep). The apply removes the chosen card from its owner's `victory` and calls `resolveVillainCityEntry` in `chainVillainFightPick` (which holds `random` + `DEFAULT_IMPLEMENTATION_MAP`).
- **Jack O'Lantern's Escape is the Viper skeleton.** A no-choice, per-player conditional Wound resolves inline inside `resolveVillainEscape` via the `onEscape` executor, not the D-24750 discard FIFO; the predicate is "fewer than two cards typed `henchman` in that seat's `victory`," evaluated current player first then clockwise (D-24780), with the current player's Wound counted in `woundsDrawn` (D-24732 posture).

Pre-deploy `initialState` blobs keep their hooks and carry no Thunderbolts markers, so stored matches play and replay identically (D-24749 §12 / D-24750 §11); only matches created after the deploy see the change.

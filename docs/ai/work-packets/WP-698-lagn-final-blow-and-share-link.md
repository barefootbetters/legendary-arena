# WP-698 — LAGN Final Blow field + loadout share-link (lagn-spec + registry-viewer)

**Status:** Draft 2026-09-14
**Primary Layer:** Shared Tooling (lagn-spec public spec) + App (registry-viewer)
**User-Visible Surface:** cards.legendary-arena.com Loadout tab — a Final-Blow loadout now survives LAGN export/import and the Copy-Setup-Link round trip
**Dependencies:** WP-686 (envelope `finalBlow?` + engine consume) ✅, WP-687 (endgame gate + UI) ✅, PR #2047 (loadout-builder `finalBlow` toggle) ✅ — all on `main`
**Baseline:** drafted against `origin/main` @ `d406f3d7`

---

## Goal

After this session, the optional **Final Blow** rule that the loadout builder can
already author (PR #2047, `draft.finalBlow`) survives the two loadout transports
that today silently drop it: the **LAGN** export/import and the **Copy Setup
Link**. The public LAGN spec gains one additive optional field,
`setup.final_blow?: boolean`, minted at a new **LAGN 1.6.0** version — exactly the
versioned-additive-field path `setup.support_pools` (1.1.0) and
`setup.hero_alternates` (1.3.0) took. The registry-viewer LAGN exporter emits
`setup.final_blow` when the draft has Final Blow on; the importer reads it back
into `draft.finalBlow`; and the share link (`setupUrlParams`) carries a
`finalBlow` query param so a Final-Blow loadout round-trips through a shared URL.
No engine, determinism, persistence, or hash surface is touched — this is a
loadout-transport/spec change only.

**Packet-specific:**

  document remains valid at 1.6.0. `migrate_1_5_0_to_1_6_0` is a pure restamp —
  no structural transform.

  (never `===`), so a future 1.7.0 document is not rejected. Confirm no `===
  LAGN_VERSION` equality gate is introduced.

  non-Final-Blow loadout's LAGN and URL are byte-identical to today except for

  producers to 1.6.0; because every gate is ordinal this rejects nothing. The
  only test churn permitted is updating example/snapshot version literals the
  scaffold run surfaces — never weakening a gate.
- **No engine import in the spec or the app transport.** `lagn-spec` stays
  self-contained (zod only); registry-viewer transport reads the draft, never
  the engine.
- **Regenerated schema must be a clean additive diff.** After `build`, confirm
  `git diff packages/lagn-spec/schemas/lagn-v1.json` shows only the `final_blow`
  property + the `1.6.0` version enum entry; revert and investigate any other

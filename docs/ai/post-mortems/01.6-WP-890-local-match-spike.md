### 6. Hidden-Coupling Detection

- [x] **Silent null state.** boardgame.io 0.50.2 creates a local match with `setupData: undefined` and drops the refusal; the game copy's `validateSetupData` bypass is gated behind an explicit `validateMatchSetup` that throws first.
- [x] **Module-level registry holder.** `setRegistryForSetup` is process-wide; in the browser only the spike sets it. Every client (page, New seed, replay) sets the same bundle reader.
- [x] **Board component state outlives a match.** Found in AC 7: after **New seed** the Battle Brief kept its "Beginning…" state because `PlayViewport` wasn't remounted. Fixed by keying `PlayViewport` on a per-start counter; re-verified (Begin the Battle → new match left the lobby; a 14-move replay matched).
- [x] **`Local()` master map is never pruned.** Each New seed adds a master to boardgame.io's module-level map for the page's lifetime. Acceptable for a dev route; a shipping host (slice 1+) should reuse one game object per match or reload.
- [x] **Flag form.** The `typeof import.meta.env === 'object'` form is false under tsx and dead-code-eliminated when unset (verified by the empty AC 6 search).

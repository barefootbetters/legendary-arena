### 5. Mutation, Aliasing, & Reference Safety

### 6. Hidden-Coupling Detection

- [x] **Scoped CSS still reaches the image.** `.img-wrap img`, `.img-wrap img.split-left/right` (grid) and `.img-wrap img` (panel) match `CardFaceImage`'s root `<img>`, which Vue stamps with the parent's scope id. No style moved.
- [x] **Parent `@error` listener.** The typed `defineEmits` keeps the grid's inline dimming handler off the `<img>`, so a tier failure never dims a tile; `emit('error', event)` passes the `Event`, so the handler's `$event.target` stays defined (both EC failure smells).
- [x] **Lint.** A self-closing `<img />` in the new component added one `vue/html-self-closing` warning (534); written as a void element, the count is back to the 533 baseline.

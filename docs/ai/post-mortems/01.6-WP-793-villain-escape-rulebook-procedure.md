### 6. Hidden-Coupling Detection

- [x] **Import cycles.** `villainEscapeProcedure` ↔ `seatChoice.resolve`, `resolveReturnOnDiscard`
  ↔ `seatChoice.resolve`, and `villainEscapeProcedure` → `phaseCard` → … → `villainDeck.reveal` →
  `villainEscapeProcedure`. Every cross-reference sits inside a function body; there is no
  top-level map keyed by an imported constant. Each import carries the cycle note.
- [x] **The opener wait.** `hasAnyPendingChoice` (now exported from `phaseCard.ts`, body unchanged)
  covers the open seat choice, return-on-discard and every active-player queue; the opener also
  waits on `pendingHeroChoice`. Without the wait a Juggernaut Escape's hand-KO pick and the escape
  prompts would stack (revert proof 5).
- [x] **Mixed stage ride.** The Bystander discard is parked with no active-seat skip unless the
  active seat is the only addressed seat; with the D-24648 skip boardgame.io would admit only the
  non-active seats (revert proof 7 fails the real-reducer case).
- [x] **Depletion.** An automatic KO's refill can empty the Hero Deck; the opener re-checks pile
  depletion before the next step, and `turn.onMove` re-runs the final-turn latch and depletion
  check after the openers.

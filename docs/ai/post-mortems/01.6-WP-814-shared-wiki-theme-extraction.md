### 6. Hidden-Coupling Detection

- [x] **Hugo's equivalent layout paths.** The shadow check encodes Hugo 0.161.1's lookup equivalences
  (`_default/X` ↔ `X`, `partials/` ↔ `_partials/`, and so on). A Hugo upgrade must re-verify them (WP Limitations); the
  matrix cases are the regression test.
- [x] **Windows `File.Dir` at the content root is `\`.** The locked `$dir` normalization turned it into `/`, which made
  `path.Join` clamp `../x` onto `/x` and defeated the out-of-tree rule. The fixture caught it on the first Windows
  build (`../README.md` warned). The hooks and `include-section` now also drop a leading `/`. This is the same class
  of bug as pre-flight pass 3's PS-1, one level further in.
- [x] **E's filename special cases.** The engine treats `architecture-inventory.md` and `changelog.md` by name. The
  theme replaces both with page params (`links_from: repo-root`, `canonical-source`). The shadow injected them into
  its scratch copies, and step 4 must make the generators emit them, or those pages' links and footer regress.
- [x] **Minified HTML.** `Compare-WikiBuild.ps1` and the fixture check parse Hugo-minified HTML: unquoted attributes,
  and an alt text holding `>`. Their tag patterns skip quoted values. Without that, an image whose `src` followed such
  an alt would have paired as empty-on-both-sides, which is a vacuous pass.

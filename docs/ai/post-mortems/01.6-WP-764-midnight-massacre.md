- [x] **Zones hold `CardExtId` strings only.** A Switchblade is a `'villain'`-typed, `'switchblade'`-origin card; the overlay (`G.convertedVillainOrigins`) is written only in a Midnight Massacre match and is the lazy, omit-when-empty field it already is, so every other scheme's `G` serializes byte-identically.
- [x] **Determinism.** The conversion is gated on the scheme id with a non-empty id list; every other scheme (and the both-Blades no-op) makes no `ctx.random` draw — proven by the "one Shuffle fewer" test. The one new Shuffle runs after the Skrull and Micro-Sized conversions (both passthroughs here), so it is the last setup draw, and two same-seed builds give the identical Villain Deck order (tested).
- [x] `ConvertedVillainOrigin` widens append-only; `SchemeTwistResolverId` gains `'midnight-massacre'`. No notable-event resolver key was added (the twist logs via `pushLog`, like `counterOnly`), so `SchemeTwistResolverKey` / `SCHEME_TWIST_RESOLVER_KEYS` and the replay-affecting phrase map are untouched — the diff stays in the allowlist and no replay hash moves.

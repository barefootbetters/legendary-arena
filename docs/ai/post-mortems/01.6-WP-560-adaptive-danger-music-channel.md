### 4. Representation & Determinism Audit

- [x] The manifest is data-only (`Record<MenaceTier, string>`) and
      JSON-serializable. The engine holds `Howl` handles, but it is
      module-local and **never** enters `G` or any serialized surface — the
      WP-412 rule restated.
- [x] Deterministic: the consumer's output is a pure function of the tier
      sequence it observes. No clock, no randomness, no memoized state beyond
      the deliberate last-seen tier.
- [x] Fails safe: an absent tier plays nothing; a blocked gate is a silent
      no-op and is **never** queued to blast on unlock; nothing throws.

Nothing enters `G` and the engine is untouched, so **no determinism or hash
surface exists to move**.

**A test-authoring bug I introduced and fixed.** My first
`useAdaptiveMusic` tests asserted synchronously against Vue's `watch`, which
flushes on the next microtask — six tests failed for a reason that had
nothing to do with the code. Adding `await nextTick()` fixed five. The sixth
was more interesting: batching three tier assignments into one tick made Vue
coalesce them to the **last** value, silently skipping `rising` — so the test
would have "passed" a two-step escalation while claiming to test three. Fixed
by ticking **once per assignment**, which is also what production does (one
snapshot per frame), with a `// why:` recording it.

**Notes / Follow-ups:**

1. **The assets are the only thing standing between this and observable
   done.** Three CC0 loops must reach `audio/music/` on R2. Until then the
   code is inert in production — the engine will construct a `Howl` for a
   404 URL and play silence, which is the correct fail-soft behaviour but is
   indistinguishable from "the feature didn't ship". Worth verifying the
   files are reachable *before* concluding anything from a live match.
2. **No endgame sting.** The bed stops at `gameOver` and nothing replaces it,
   so a match currently ends into silence. That is the locked v1 behaviour
   (D-24369 §5), but it will read as abrupt until the Surface-4 resolution
   sting packet lands. Worth sequencing that sooner rather than later now
   that music exists.
3. **`MUSIC_CROSSFADE_MS` is a guess.** 1500 ms was chosen so a tier change
   reads as a mood shift rather than a cut, but it has never been heard
   against real loops. Expect to tune it once the assets exist; it is a
   single exported constant, deliberately.
4. **Two engines now exist and a future reader will want to merge them.**
   The `// why:` at the top of `musicEngine.ts` and the EC's first failure
   smell both exist to prevent that. If the SFX layer ever legitimately needs
   looping, the right move is to reconsider the split explicitly via a new
   D-entry — not to quietly widen `HowlLike`.
